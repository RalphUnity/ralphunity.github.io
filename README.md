## Editing

- **Name, description, email, LinkedIn:** edit the "ABOUT" section in `index.html`. The name also appears in the `<title>`, the header and the footer.
- **Projects:** edit `data/projects.js`. Each project has a `name`, a `description`, a list of `tasks`, and lists of `images` and `videos`.
- **Images and videos:** put the files in `images/projects/` and list their paths in the project, e.g. `"images/projects/screenshot.png"`. Videos can be `.mp4` files or YouTube links.

To preview the site, open `index.html` in a browser.
